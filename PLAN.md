## 0. How to read this plan

- IDs: `P-###` Paul (Engine/ML), `J-###` Jess (App/UX/Learning), `L-###` Leto
  (CI/Integration/Arbitration), `X-###` cross-cutting (Leto assigns owner).
  First digit = milestone.
- Sizes: `S` ≤ 1 session, `M` ≈ 2–3 sessions, `L` ≈ 4–6 sessions, `XL` > 6 → split it.
- `Deps` are task IDs. `CI` names the job(s) a task fires. **Fire-and-continue
  (AGENTS §5): push → dispatch → record run on the queue row → claim next independent
  task. Never wait on CI.**
- Each milestone ends with a **Merge Gate** (Leto checks), a **Device Demo** (human
  runs the unsigned IPA on the iPhone 12 Pro Max and logs results in QUEUE LOG), and
  **Parallelization notes** (what each agent does while the others' builds run).
- Contracts version bumps are additive within a milestone; breaking changes need a
  Leto ruling + migration task.
- **Honesty rule:** every engine task logs measured numbers (RTF, RSS, F1, SDR) in
  `Docs/BENCHMARKS.md`. No overclaiming. Per-part separation of close male harmony
  WILL bleed; design for it (confidence, focus mixes, score alignment, correction UI).

### Benchmark targets (from Docs/RESEARCH.md — honest, not aspirational)

| Metric | Target | Source of truth |
|---|---|---|
| Live monophonic pitch F1@50c (synthetic clean) | ≥ 0.75 | SwiftF0 0.781 / RMVPE 0.768 (pitch-benchmark) |
| Live pitch RTF on A14 | < 0.3 | SwiftF0 180× RT / NanoPitch RTF 0.1–0.3 WASM |
| Live feedback latency | < 100 ms | NanoPitch causal (0 lookahead); SwiftF0 176 ms for grading only |
| Separation SDR (vocals, synthetic) | ≥ 8 dB | htdemucs ~9.2; windowed-roformer 11.17 MUSDB |
| Per-part NSDR (real acapella, post-v1 fine-tune) | 4–14 dB by part | ACappellaSet S4.05/A4.41/T7.91/B10.50; jaCappella MRDLA |
| Part-aware note F1 (real, heuristic assignment) | 0.2–0.4 honest | PawCT 0.225 macro @50 ms is published SOTA |
| Peak RSS during separation | < 1.5 GB | A14 6 GB jetsam ~3 GB |
| Core model bundle | < 200 MB | demucs fp16 81 MB + SwiftF0 ~60 KB + NanoPitch ~1.3 MB + basic-pitch ~2 MB + silero ~2 MB |

### Fixture policy (all milestones)

- All git-committed audio fixtures are **synthetic, seeded, ≤ 1 MB each**, generated by
  `scripts/fixtures/gen.py` (P-001): sine sweeps 46–2100 Hz, synthetic SATB mixtures
  (C3/E3/G3/C4 voicings), click tracks, silence, noise bursts. No copyrighted audio in git.
- Real SDA songs are used **locally on the device** for demos only; never committed.
- Model weights live in the project Hugging Face repo (L-005), SHA256-verified, never in git.

### Human touchpoints (the owner does these; agents queue-block on them explicitly)

1. Create HF model repo + grant CI access if private (D2). Public permissive models → no token.
2. Install unsigned IPA via SideStore/LiveContainer at each Device Demo; run checklist; log results.
3. Provide real SDA acapella files locally for M2–M5 demos (not committed).
4. Rule on bundle id / signing / App Store intent (D3) — sideload first.
5. Approve any post-v1 training run that uses external datasets (license gate).
