# PitchNotes-iOS

A 100% offline iPhone app for learning SDA a cappella voice parts: import a song,
remove/separate instruments and voice parts, then sing along with live pitch matching
and grading, plus music-theory and ear-training exercises derived from the song.

**Status:** scaffold — governance files only. Start with [AGENTS.md](AGENTS.md):
this repo is built by three agents (**Paul**, **Leto**, **Jess**) in three separate
chats. The task board is [QUEUE.md](QUEUE.md); the milestone plan ([PLAN.md](PLAN.md))
and contracts ([CONTRACTS.md](CONTRACTS.md)) govern what gets built and how lanes
interface.
